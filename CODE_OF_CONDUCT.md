# Code of Conduct

SUS Toolkit is intended to be a professional, collaborative and technically rigorous open-source project.

Contributors are expected to:

- discuss code and ideas respectfully;
- critique technical decisions without attacking people;
- avoid harassment, discrimination and intimidation;
- protect patient privacy and operational security;
- never post real sensitive health data, credentials or secrets;
- document disagreements with evidence and official references where possible.

Maintainers may edit or remove content, close discussions or restrict participation when behavior threatens contributors, patient privacy, project security or constructive collaboration.

If a conduct issue includes sensitive information, do not report it publicly. Use the same private reporting path described in `SECURITY.md`.
